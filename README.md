# KodNest Premium Build System — Design System

This repository contains the design system and component library for "KodNest Premium Build System" — a serious, calm, and coherent B2C design system.

What's included
- Design tokens (colors, spacing, typography)
- Global styles and component primitives (Button, Input, Card, TopBar, SecondaryPanel, ProofFooter)
- A minimal Vite + React demo to preview components

Design philosophy and rules are captured in `DESIGN_GUIDELINES.md`. Start with:

Install

1. npm install
2. npm run dev

Notes
- This is the design system scaffold — it intentionally contains no product feature logic. See DESIGN_GUIDELINES.md for the full system rules.
